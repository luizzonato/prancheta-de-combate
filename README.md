# Prancheta de Combate

PWA de hábitos, treino e medidas do protocolo cutting (PPL + cardio zona 2).
Sem build e sem dependências: HTML, CSS e JS puros. Os dados ficam no aparelho (localStorage) e o app funciona offline.

## Rodar
```bash
python3 -m http.server 8765   # abra http://localhost:8765
```

## Instalar no celular
Publique a pasta em qualquer hospedagem estática com HTTPS (GitHub Pages, Netlify, Render Static Site)
e use "Adicionar à tela inicial" no navegador.
